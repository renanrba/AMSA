# Questionário de Discovery — Fase 0 (Comunidade de Prestadores de Serviço)

**Uso:** roteiro de entrevista para a Fase 0 do módulo (ver `docs/analise-marketplace-prestadores-servico.md`, seção 4). Meta: 10–15 entrevistas com gestores e 10–15 com prestadores, antes de validar categorias, preço de assinatura e cidades piloto.

**Como usar:** entrevista guiada (não formulário autopreenchido) — ler a pergunta, deixar a pessoa responder livremente antes de mostrar as opções, e só então marcar a alternativa mais próxima. As perguntas abertas são o material mais valioso: registrar a resposta o mais literal possível, com exemplos e números reais quando a pessoa der.

---

## Parte A — Questionário para Gestores

5. **Conte a última vez que um problema de manutenção atrasou ou prejudicou um check-in. O que aconteceu?** *(aberta)*

6. **Qual desses problemas é o mais frequente para você?**
   ( ) Elétrica ( ) Hidráulica ( ) Ar-condicionado ( ) Limpeza ( ) Chaveiro ( ) Internet/Wi-Fi ( ) Outro: ______

   ( ) Menos de 2h ( ) Meio dia ( ) Um dia inteiro ( ) Mais de um dia

## Parte B — Questionário para Prestadores de Serviço

### Perfil

1. **Qual seu principal ramo de atuação?**
   ( ) Elétrica ( ) Hidráulica ( ) Ar-condicionado ( ) Limpeza ( ) Chaveiro ( ) Dedetização ( ) Jardinagem/Piscina ( ) Pintura ( ) Manutenção geral ( ) Outro: ______

2. **Você atua como autônomo (MEI) ou tem empresa com equipe?**
   ( ) Autônomo/MEI ( ) Pequena empresa (2–5 pessoas) ( ) Empresa média ou maior

3. **Em quantos bairros/cidades você consegue atender hoje?** *(aberta)*

### Dor atual

4. **Como você consegue a maioria dos seus clientes hoje?** *(múltipla seleção)*
   ( ) Indicação boca a boca ( ) Grupos de WhatsApp ( ) Redes sociais ( ) Apps tipo GetNinjas/99 ( ) Clientes fixos/recorrentes ( ) Panfleto/placa ( ) Outro: ______

5. **Em média, quanto tempo você fica ocioso (sem novos chamados) entre um serviço e outro?**
   ( ) Nunca fico ocioso ( ) Alguns dias ( ) Uma ou duas semanas ( ) Mais de um mês

6. **Qual sua maior dificuldade hoje para conseguir mais clientes?** *(aberta, sugerir se travar: visibilidade, custo de divulgação, concorrência desleal de preço, falta de confiança de cliente novo, região de atuação limitada)*

7. **Você já pagou por algum aplicativo/plataforma para divulgar seus serviços (GetNinjas, 99, etc.)?**
   ( ) Pago atualmente ( ) Já paguei, não uso mais ( ) Nunca paguei

8. **Se já pagou ou paga: o que acha do custo-benefício?** *(aberta)*

### Percepção da plataforma

9. **O que você acha de uma plataforma exclusiva para gestores de imóveis de temporada (Airbnb) buscarem prestadores como você?**
   1 — Nenhum interesse … 5 — Muito interessado — **por quê?** *(aberta)*

10. **Você toparia pagar uma assinatura mensal ou anual para ficar visível e receber chamados de gestores de temporada da sua região?**
    ( ) Sim, sem dúvida ( ) Sim, dependendo do preço ( ) Talvez ( ) Não

11. **Qual faixa de valor mensal você consideraria justo pagar por isso?**
    ( ) Até R$29 ( ) R$30–59 ( ) R$60–99 ( ) R$100–150 ( ) Mais de R$150 ( ) Não pagaria

12. **O que seria mais importante para você nessa plataforma?** *(escolher até 3)*
    ( ) Leads qualificados de verdade ( ) Mostrar minhas avaliações/reputação ( ) Preço de assinatura acessível ( ) Divulgar portfólio/fotos ( ) Sem concorrência de preço predatória ( ) Facilidade de contato direto

13. **Você se sentiria confortável recebendo avaliações públicas (nota + comentário) dos gestores após cada serviço?**
    ( ) Sim ( ) Sim, desde que possa responder ( ) Não

### Fechamento

14. **O que faria você recomendar essa plataforma para outros colegas de profissão?** *(aberta)*

15. **Tem algo que você gostaria de ver numa plataforma assim, que nenhum app parecido oferece hoje?** *(aberta)*

---

## Notas para quem for aplicar

- Não ler as opções antes da resposta livre — a pergunta aberta primeiro evita induzir a resposta.
- Perguntas 10–11 (gestor) e 9–11 (prestador) são as mais sensíveis a viés de cortesia ("eu pagaria" é fácil de dizer em entrevista) — vale cruzar com a pergunta 7/8 do lado prestador (o que já pagou de fato hoje) para calibrar disposição real a pagar.
- Guardar respostas por cidade/bairro do entrevistado — alimenta a decisão de cidades piloto (pergunta em aberto na seção 15 do estudo de viabilidade).
